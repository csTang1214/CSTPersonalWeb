About Me

Developer, tinkerer, and lifelong learner

I'm a Computer Science student (graduating 2026) with a passion for building intelligent, user-focused systems. My journey began with game development — I've published two 2D mobile platformer games on the Google Play Store with 1,000+ downloads each, which taught me the discipline of shipping polished products and iterating on user feedback.

That foundation evolved into a deep interest in Artificial Intelligence and Machine Learning. I've since designed and shipped several production-grade AI projects spanning MLOps pipelines, conversational AI, and fully on-device mobile inference.

My most recent project, Pocket Romance — an offline, on-device AI companion app — started life as a Unity prototype before I rebuilt it in React Native for real on-device LLM and voice performance. I'm preparing for the AWS Certified Developer – Associate certification and plan to explore Reinforcement Learning — starting with adaptive boss AI in games and portfolio trading agents. I'm particularly interested in roles at the intersection of AI Engineering, MLOps, Mobile AI, and Game AI.

SentinelFlow

Event-Driven MLOps Pipeline with Human-in-the-Loop Governance

An AWS-native ML pipeline that automates data ingestion, transformation, and fraud prediction — with built-in human review gates using Step Functions' waitForTaskToken pattern. The pipeline literally pauses and waits for human approval before continuing, mirroring real-world MLOps governance. Features a Streamlit dashboard for approvals and a FastAPI inference endpoint.

ClinicCS

Full-Stack Conversational AI Clinic Management System

Patients interact with a chatbot to book, reschedule, and cancel appointments through natural language. Powered by a two-model LLM architecture: a fast 8B classifier routes intent, then a 70B model handles generation with RAG-backed clinic information. Dynamic UI components (date pickers, slot pickers) inject inline into the chat thread.

React 19 TypeScript TanStack Query Node.js / Express LangChain / LangGraph RAG + pgvector Groq API PostgreSQL Redis Vercel + Render
🤖 Two-model architecture: 8B classifier + 70B generator
🔒 JWT auth, bcrypt (12 rounds), Helmet, rate limiting
🔄 Three-layer fallback chain for graceful degradation

MAIA

Fully On-Device Mobile AI Assistant for Android

Every feature — LLM inference, speech recognition, document search, OCR, and image generation — runs 100% locally on the device. No user data is ever sent to a server. Supports 9 on-device models (135M–4B params), a hands-free voice mode built for accessibility, and a BM25 document vault for personal knowledge retrieval.

React Native (Expo) TypeScript ExecuTorch Stable Diffusion TF-IDF / BM25 ML Kit OCR SQLite Expo Speech
🔇 9 on-device models — zero server calls, full privacy
🗣️ Voice mode: STT → agent loop → TTS with auto-resume
📚 Document vault with TF-IDF semantic search across PDFs
